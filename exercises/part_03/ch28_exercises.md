# Chapter 28 Exercises

1. Define an explanatory question in one sentence.
2. Define an inferential question and name the quantity it requires.
3. Define a predictive question using an NRG shipment.
4. Define a decision question using the same shipment.
5. Explain why one regression can have different interpretations under different purposes.
6. Classify this question: What proportion of Jakarta warehouse orders were late in August?
7. Classify this question: Does assigning an additional loader reduce departure delay?
8. Classify this question: Which orders will miss tomorrow's dispatch cut-off?
9. Explain why a weather alert can be predictive without being an action NRG can use causally.
10. Give one feature that would be unavailable at dispatch prediction time.
11. If expediting costs 15 units and an unaddressed late shipment costs 100 units, calculate the simplified decision threshold.
12. For late probabilities 0.08, 0.20, and 0.45, apply the threshold from Exercise 11.
13. Explain why 95 percent accuracy can be useless when lateness prevalence is 5 percent.
14. Name two pieces of evidence needed for an explanatory claim and two for a predictive claim.
15. Draft a decision record for allocating 50 daily quality-inspection slots.
16. Write four separate questions about product returns, one each for explanation, inference, prediction, and decision.
