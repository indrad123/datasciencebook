# Chapter 29 Exercises

1. Explain why "use AI to improve sales" is not yet an analytical problem.
2. Rewrite that request as a descriptive question.
3. Rewrite it as a predictive question.
4. Rewrite it as a decision question with an action and capacity constraint.

7. Write an operational definition for a damage-related return.
8. Explain the difference between a business outcome, target, and proxy.
9. Give one way that optimizing complaint counts could create harmful behaviour.

11. Name three conditions required for a prediction to be actionable.
12. Explain why a post-delivery complaint note cannot be used for a pre-dispatch score.
13. Name four data elements to verify before modelling a return-risk target.
14. Identify three stakeholders affected by an inspection-allocation model and one possible harm for each.
15. Draft a complete analytical problem statement for forecasting daily noodle demand at one warehouse.
16. Apply the ten-item readiness test to a proposed employee-turnover model and identify the first discovery action.
