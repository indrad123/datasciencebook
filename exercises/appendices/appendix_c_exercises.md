# Appendix C Exercises: Mathematical Symbols and Notation

1. Explain the difference between $=$ and $\approx$.
2. Translate $x\in[0,1)$ into words.
3. Let $A=\{1,2,3\}$ and $B=\{3,4\}$. Find $A\cap B$, $A\cup B$, and $A\setminus B$.
4. Expand $\sum_{i=1}^{4}2i$ and calculate it.
5. Write the mean of five observations using sigma notation.
6. Explain why mathematical index 1 often corresponds to Python index 0.
7. If $f(x)=2x+1$ and $g(x)=x^2$, calculate $(f\circ g)(3)$.
8. State the shapes of $\mathbf{X}$ and $\mathbf{w}$ when $\mathbf{X}\in\mathbb{R}^{100\times5}$ and $\mathbf{w}\in\mathbb{R}^{5}$, then state the shape of $\mathbf{Xw}$.
9. Calculate $[1,2,3]^{\mathsf T}[4,0,-1]$.
10. Calculate $\lVert[3,4]\rVert_2$.
11. Distinguish $\Delta y/\Delta x$ from $dy/dx$.
12. Translate $P(A\mid B)$ and state what the vertical bar means.
13. Explain the distinction between $Y$, $y$, $\mu$, and $\hat\mu$.
14. If 18 of 24 deliveries are on time, estimate $P(\text{on time})$ empirically.
15. Explain what $\arg\min_{\theta}L(\theta)$ returns.
16. In $y_{t-7}$, what must be known before interpreting the lag?
17. Translate $\forall x\in A, f(x)\ge0$ into words.
18. Identify the dimensional error in adding 12 cases to 5 cases per day.
19. Implement $\sum_i w_ix_i$ in Python and describe two validations it needs.
20. Write a notation key for an NRG demand model using $\mathbf{X}$, $y_t$, $\hat y_{t+h}$, $T$, and $h$.
