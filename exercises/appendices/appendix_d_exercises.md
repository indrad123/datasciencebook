# Appendix D Exercises: Glossary

1. Distinguish an algorithm from a model.
2. Explain why accuracy may be unsuitable for a rare-event problem.
3. Distinguish a parameter, statistic, estimate, and estimator.
4. Distinguish correlation from a causal effect.
5. Explain the relationship among a feature, target, label, and prediction.
6. Distinguish data drift from model drift.
7. Distinguish a validation set from a test set.
8. Explain how data leakage can make an evaluation look unrealistically strong.
9. Distinguish precision from recall using a shipment-alert example.
10. Explain why an outlier is not automatically a data error.
11. Distinguish standard deviation from standard error.
12. Explain the roles of a loss function, objective function, gradient, and learning rate.
13. Distinguish calibration from classification accuracy.
14. Distinguish supervised, unsupervised, and generative modelling tasks.
15. Explain the relationship among forecast origin, horizon, and target time.
16. Distinguish regularisation from normalisation.
17. Explain why “inference” must be interpreted from context.
18. Choose five glossary terms needed to describe an NRG late-shipment classifier.
19. Write a definition of “dashboard” that identifies the concept without using the word itself.
20. Identify two terms whose meanings change substantially by context and state how a writer should handle them.
