# Chapter 6 Exercises

1. Expand and evaluate \(\sum_{i=1}^{4}i\).
2. Expand \(\sum_{j=2}^{5}(3j-1)\).
3. How many terms occur in \(\sum_{i=0}^{8}x_i\)?
4. Write \(7+10+13+16\) using sigma notation.
5. Evaluate \(\sum_{i=1}^{5}4\).
6. If \(x=(3,5,2,6)\), calculate \(\sum_{i=1}^{4}x_i\) and its mean.
7. Simplify \(\sum_{i=1}^{n}(2x_i+3)\).
8. Prices are \((20,30,25)\) and quantities are \((10,5,8)\). Calculate \(\sum p_iq_i\).
9. Observations are \((10,12,9)\) and predictions are \((11,10,9)\). Calculate SSE.
10. Calculate the grand total of \(\begin{bmatrix}10&12&8\\7&9&11\end{bmatrix}\).
11. For values \((80,120,150,90)\), calculate the sum and count of values above 100.
12. Explain why \(\sum_{i=1}^{n}x_j=nx_j\) when \(j\) is fixed.
13. Translate \(\sum_{i=1}^{6}i^2\) into a Python expression using `range`.
14. Explain the relationship between mathematical \(x_1\) and Python `x[0]`.
15. State one unit check for \(R=\sum p_iq_i\).
16. Challenge: If \(\sum_{i=1}^{n}x_i=50\), find \(\sum_{i=1}^{n}(3x_i-2)\) in terms of \(n\).
