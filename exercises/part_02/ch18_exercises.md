# Chapter 18 Exercises: Probability Distributions

1. Distinguish a random variable from an observed value.
2. Explain the difference between discrete and continuous distributions.
3. Model one shipment as late or on time with a Bernoulli variable.
4. If late probability is 0.1, find the probability that exactly two of five independent shipments are late.
5. State the binomial assumptions and identify one realistic violation.
6. If complaints average two per hour under a Poisson model, find the probability of zero complaints in an hour.
7. Explain why rate stability matters for a Poisson model.
8. Give an NRG example suited to a uniform model.
9. For a uniform variable from 10 to 20, find `P(X <= 14)`.
10. State the parameters of a normal distribution and their effects.
11. For `X ~ N(100, 15)`, express `P(X <= 115)` using a standard normal variable.
12. Give an NRG waiting-time example for an exponential model.
13. If an exponential rate is 0.5 per hour, find `P(X <= 2)`.
14. Explain why a good-looking histogram alone does not validate a distribution.
15. Compare a probability mass function, density, and cumulative distribution function.
16. Write a checklist for selecting and checking a probability model.
