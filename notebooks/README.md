# Notebooks

The notebooks follow the book's chapter and appendix structure.

## Use

1. Complete the setup in the repository root `README.md`.
2. Start JupyterLab from the repository root with `jupyter lab`.
3. Open the notebook matching the chapter you are reading.
4. Run cells in order so relative data paths resolve consistently.

Notebook directories retain the book's part numbering. A missing part directory means that the corresponding book part has no executable companion notebook; it is not a numbering error.

All company and operational examples use synthetic data unless a notebook explicitly identifies another source.
