# Appendix D Solutions: Glossary

1. An algorithm is a procedure; a model is a formal mapping or representation, often produced by an algorithm.
2. Predicting every case as the common class can produce high accuracy while detecting none of the rare events and creating unacceptable consequences.
3. A parameter is an unknown model or population quantity; a statistic is calculated from data; an estimate is a calculated approximation; an estimator is the rule used to calculate it.
4. Correlation summarises association. A causal effect contrasts outcomes under interventions and requires additional identification assumptions or experimental design.
5. A feature is an input, the target is what the model aims to predict, a label is an observed target attached to an example, and a prediction is the model's estimate.
6. Data drift is change in monitored data distributions. Model drift is change or deterioration in model behaviour or consequences.
7. Validation data guide choices during development. A protected test set assesses the fixed final procedure.
8. Leakage supplies information that would be unavailable in real use or violates the evaluation split, allowing the model to exploit an unfair signal.
9. Precision asks what fraction of shipment alerts truly become late. Recall asks what fraction of all late shipments received an alert.
10. It may be a valid rare case, a changed process, a subgroup, or an error. Its provenance and context must be investigated.
11. Standard deviation describes spread in observed values. Standard error describes uncertainty or repeated-sample variability in an estimator.
12. Loss penalises an outcome; the objective is optimised and may combine loss with penalties; the gradient gives local change directions; the learning rate scales updates.
13. Calibration compares probabilities with event frequencies. Accuracy evaluates hard class decisions and depends on a threshold.
14. Supervised learning uses targets, unsupervised learning studies inputs without a designated target, and a generative model represents a data distribution that can support sampling.
15. The origin is the latest time whose information is available, the horizon is the distance ahead, and the target time is origin plus horizon.
16. Regularisation controls model complexity or generalisation. Normalisation rescales or transforms values under a specifically named procedure.
17. It may refer to statistical reasoning, model execution, or broader reasoning from evidence. The surrounding task must specify which meaning applies.
18. One valid set is feature, label, classification, decision threshold, and recall. Other coherent sets are acceptable if each term's role is explained.
19. Example: “A visual interface that presents selected measures, trends, alerts, and controls for monitoring and decision support.”
20. Examples include bias, kernel, normalisation, sensitivity, and inference. Define the intended meaning locally and avoid switching meanings silently.
