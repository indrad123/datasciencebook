# Security policy

## Reporting a vulnerability or exposed secret

Please do not disclose security issues, credentials, personal data, or other sensitive material in a public issue.

Use GitHub's private vulnerability-reporting feature for this repository. Include the affected path, the potential impact, and safe reproduction steps. Allow reasonable time for investigation before public disclosure.

## Scope

This repository is an educational companion. Its examples and datasets are not production systems or operational advice. Dependencies should be installed in an isolated virtual environment and reviewed before use in a sensitive environment.
